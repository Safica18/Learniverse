# Learniverse

Learniverse is a web-based gamified educational platform developed as my Final Year Project at Birmingham City University to support mathematics learning for Key Stage 1 and Key Stage 2 students.

## Features

* Interactive educational gameplay
* Mathematics learning activities
* User-friendly interface for young learners
* Gamified learning experience

## Technologies Used

### Frontend

* React
* HTML
* CSS
* JavaScript

### Backend

* PHP

### Database

* SQL / MySQL

## Project Structure

* Frontend – User interface and interactive gameplay
* Backend – Server-side functionality
* Database – Data storage and management
